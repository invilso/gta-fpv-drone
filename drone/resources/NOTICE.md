# Resource provenance

- **Inter.ttf** — the Inter typeface, downloaded automatically on first run
  from Google Fonts' repository mirror (see `../font.lua`). Licensed under
  the SIL Open Font License 1.1 — see `Inter-OFL.txt` in this folder.
- **drone_motor.wav** — a synthesized motor-hum loop generated offline from
  scratch (summed detuned sine oscillators over an exact 1-second buffer,
  see `../docs/audio.md`), not a recorded or downloaded sample. No
  third-party license applies.
